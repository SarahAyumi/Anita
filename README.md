## Objetivo do software 
O sistema Anita visa organizar o processo de compras e vendas de um estúdio de arte. O cadastro em um banco de dados será utilizado para gerenciar fluxo financeiro, demandas de matéria-prima e produtos mais adquiridos de forma otimizada e intuitiva para os usuários do sistema.
